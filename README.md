# 💱 Conversor de Moedas

Aplicação web para conversão entre moedas (BRL, USD e EUR) com interface intuitiva e cálculo em tempo real.

## ✨ Funcionalidades

- Conversão entre Real (BRL), Dólar (USD) e Euro (EUR)
- Validação de entrada de dados
- Resultado exibido instantaneamente
- Interface limpa e objetiva

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
